Мульти-source Merge Request

Создавайте несколько MR из разных веток за один клик. Не готовые ветки — исключайте, остальные обрабатываются автоматически.

feature/login
feature/api
feature/wip
fix/perf
MR #1 feature/login → main
MR #2 feature/api → main
MR #3 fix/perf → main

Вместо 10 минут в браузере — 30 секунд в VS Code.

Преимущества

🔀

Три Git-провайдера

GitLab, GitHub, Bitbucket — с поддержкой self-hosted инстансов. Единый интерфейс, единая лицензия.

🌿

Автосоздание веток

Если целевая ветка не существует — расширение создаст её автоматически через API.

🧠

Умное назначение ревьюера

При конфликтах MR автоматически назначается на автора последнего коммита. Контекстная логика.

🔐

Безопасное хранение секретов

Токены хранятся в OS keychain (macOS Keychain / Windows Credential Vault / Linux Secret Service).

📋

Шаблоны и история MR

Сохраняйте типовые шаблоны с плейсхолдерами. Отслеживайте историю созданных MR.

Установка

1

Установите из Marketplace

Откройте VS Code → Extensions (Ctrl+Shift+X) → найдите «MR Creator» → Install.

Установить прямо из Marketplace

2

Активируйте лицензию

Получите лицензионный ключ в Telegram боте и вставьте в расширение.

3

Альтернатива: установка из .vsix

Скачайте .vsix из GitHub Releases и установите через Extensions → ··· → Install from VSIX.

Скачать .vsix

code --install-extension a1phaZ.mr-creator
