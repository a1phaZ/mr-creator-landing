# MR Creator — маркетинговые метрики

Снятие снимка Marketplace: `node scripts/marketplace-stats.mjs` (TSV: date, version, install, downloadCount, trending d/w/m, weightedRating).
Источник — публичный Gallery API VS Code Marketplace (`alphaZ.mr-creator-ext`). Прогон не требует auth.

## Базлайн (2026-09-18)

|---|---|---|---|---|---|
| 2026-09-18 | **2.1.0** | 1 | 21 | 0 / 0 / 0 | 4.45 |

> Базлайн снят для опубликованной версии **2.1.0**. Публикация 3.0.0 — отдельная задача; после неё база переснимается для 3.0.0 и становится отправной точкой маркетинга.
> `install=1` при `downloads=21` — типичная ситуация для свежего листинга: большая часть загрузок пришлась на неактивных/ботов, установки начнут расти после онбординга и обновления листинга.
